# API Aguas!

This API is build to be used only in the Aguas! app. More information about the app in the [app-aguas repository](https://github.com/IzakCancino/app-aguas/).

## 📌 About it 

The API is connected to a database that stores user and reports information essential for the app. It has the CRUD functionalities, login and browsing methods available to use.

It is published thanks to Free ASP Hosting with this url [https://aguasss.bsite.net/](https://aguasss.bsite.net/). But is only accesible with a specific API key.
